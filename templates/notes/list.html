Como usar as notas
📝 Formatação Markdown
  • # Título → Título
  • ## Subtítulo → Subtítulo
  • **negrito** → negrito
  • *itálico* → itálico
  • ~~tachado~~ → tachado
  • - item → lista não ordenada
  • - [ ] tarefa → checklist
  • > citação → citação
  • [texto](url) → link
  • `código` → código inline
  • ```código``` → bloco de código
⌨️ Atalhos
  • Ctrl+B → Negrito
  • Ctrl+I → Itálico
  • Ctrl+K → Inserir link
  • Ctrl+S → Salvar nota
💡 Dicas
  • ✅ O preview é atualizado em tempo real
  • ✅ Salvamento automático a cada 1,5s
  • ✅ Use a toolbar para inserir formatação sem digitar
  • ✅ Associe notas a tópicos para organizar melhor
